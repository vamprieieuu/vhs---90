VHSart — Full-Frame Horizontal Static & Chroma Noise

Objective

Implement a dedicated VHSart preset that accurately reconstructs the visual appearance and temporal behavior of the supplied reference video, video_1.mov (~1.014 seconds).

The effect must reproduce dense, full-frame analog-style horizontal static with subtle-to-moderate chromatic interference. The entire frame must be covered by continuously changing, short, horizontally compressed noise segments, resembling a degraded RF/video signal or a television with no clear reception.

This must be a fully procedural effect rendered in real time by the native C++ After Effects plugin. Do not use pre-rendered images, video clips, GIFs, texture overlays, or externally generated noise assets.

1. Inspect Existing VHSart Engines First

Before implementing anything:

  • Thoroughly inspect the existing VHSart project structure and identify all current noise, static, signal interference, chroma, grain, and compositing engines.
  • Determine whether the existing engines can reproduce this reference through parameter configuration or small extensions.
  • Prefer a dedicated preset using existing engines.
  • Do not create a large redundant engine if the current architecture already supports the required behavior.
  • If horizontal segment-length control is missing, extend the most appropriate existing noise engine rather than duplicating its functionality.
  • Preserve all existing effects, presets, controls, and rendering behavior.

2. Primary Visual Component — Full-Frame Horizontal Static

Reconstruct the dominant visual component:

  • Cover 100% of the frame, from top to bottom and left to right.
  • Generate thousands of tiny, short, irregular horizontal noise segments.
  • Keep the segments vertically thin, typically around 1–2 pixels at the reference resolution, with appropriate scaling for other resolutions.
  • Make the segments horizontally compressed and variable in length.
  • Avoid long, continuous scanlines, large blocks, circular grain, or ordinary isotropic pixel noise.
  • Maintain high and relatively uniform noise density across the entire image.
  • Mix grayscale noise (white, light gray, dark gray, black) with scattered low-to-medium saturation colors.
  • Use subtle red, green, blue, cyan, and pale magenta/pink chromatic details.
  • Avoid large coherent color regions or strong RGB separation.

The result must resemble a dense, unstable analog signal rather than a conventional digital noise filter.

3. Horizontal Segment Generation

Use a fast deterministic procedural hash or equivalent noise-generation method.

Generate segment properties from spatial and temporal coordinates, including:

  • Horizontal segment position.
  • Segment length.
  • Segment brightness.
  • Grayscale or chromatic classification.
  • Chroma intensity.
  • Temporal seed.

Vary segment lengths and brightness locally while preserving the overall horizontal orientation.

Provide an adjustable horizontal segment-length parameter. It must change the actual geometry of generated noise elements, not merely scale the entire image or increase blur.

Avoid introducing a regular grid or repetitive visible pattern.

4. Temporal Behavior

The reference shows continuous per-frame changes without a clearly established periodic cycle.

Implement:

  • Continuously evolving static patterns between frames.
  • Stable average density and overall brightness.
  • Randomized local segment positions and properties.
  • Subtle frame-to-frame flicker.
  • No large periodic pulses or artificial event transitions.

Use a deterministic temporal seed derived from the user seed and the current frame/time.

Provide:

  • Animate With Time: On/Off.
  • Animation Speed.
  • Random Seed.

When animation is disabled, the noise pattern must remain frozen and repeatable.

The same seed and frame/time must always produce the same result, ensuring deterministic rendering, reproducible previews, and reliable After Effects caching.

5. Secondary Component — Near-Right Vertical Edge Line

Reproduce the extremely thin vertical line visible close to the right edge of the reference.

Requirements:

  • Position it near the extreme right edge.
  • Keep it extremely narrow.
  • Extend it vertically across most or all of the frame.
  • Allow subtle light/dark interruptions and interactions with horizontal noise segments.
  • Keep its appearance restrained and integrated into the static.

Provide an independent enable/disable control and, if appropriate, a subtle intensity control.

Do not turn this detail into a thick border or a prominent vertical distortion.

6. Chroma and Luma Architecture

The effect combines grayscale RF-like static with scattered chromatic interference.

Keep these properties independently controllable where the existing architecture permits:

  • Static Intensity.
  • Chroma Saturation.
  • Luma Variation.
  • Horizontal Segment Length.
  • Noise Density.

The grayscale component should remain visually dominant.

Do not introduce broad chroma smears, strong RGB channel displacement, large color bands, vertical rolling, geometric warping, or unrelated VHS damage.

7. Input and Compositing Modes

Support two practical operating behaviors:

Full Static / Generated Signal

  • Generate the static as the dominant output.
  • Allow it to cover the original image almost completely.
  • Preserve the reference’s consistent full-frame appearance.

Blend With Input

  • Composite the generated static over the original footage.
  • Allow the user to adjust the contribution of the original image.
  • At maximum static coverage, the image should be almost entirely obscured.
  • At lower static coverage, the underlying footage should become progressively visible.

Do not confuse static intensity with input blend. They must control different aspects of the result.

8. Proposed Initial Preset Values

Create the preset:

VHSart — Full-Frame Horizontal Static & Chroma Noise

Use the following as initial tuning estimates, not hardcoded limits:

  • Static Intensity: 90%.
  • Horizontal Segment Length: 45%.
  • Chroma Saturation: 35%.
  • Input Blend: 95% static dominance in Generated Signal mode.
  • Animate With Time: On.
  • Animation Speed: Natural per-frame evolution.
  • Random Seed: Reproducible user-controlled value.
  • Near-Right Vertical Edge Line: On, subtle intensity.

The initial preset should prioritize matching the reference rather than maximizing every parameter.

9. User Interface

Expose clear, functional controls:

  1. Static Intensity.
  2. Horizontal Segment Length.
  3. Noise Density, if not already represented accurately by the existing engine.
  4. Chroma Saturation.
  5. Luma Variation, if supported by the existing architecture.
  6. Input Blend.
  7. Animate With Time.
  8. Animation Speed.
  9. Random Seed.
  10. Near-Right Edge Line.
  11. Edge Line Intensity.

Do not add decorative controls that do not affect rendering. Reuse existing controls when their behavior already matches the required function.

10. Native After Effects Requirements

Maintain compatibility with the project’s configured After Effects target and native C++ SDK architecture.

Ensure:

  • Correct alpha preservation.
  • Correct premultiplied-alpha handling.
  • Safe processing of transparent pixels.
  • Multi-Frame Rendering compatibility.
  • Thread-safe rendering.
  • Deterministic output for identical inputs and render times.
  • Resolution-independent parameter scaling.
  • No unnecessary full-frame memory allocations.
  • No race conditions or shared mutable random-number state.
  • Correct behavior during timeline scrubbing, preview, and final rendering.

11. Reference-Matching Tests

Use the actual supplied video_1.mov as the visual reference.

Compare the generated result at matching resolution and synchronized timestamps, including approximately:

  • 00:00.000
  • 00:00.250
  • 00:00.500
  • 00:00.750

Inspect both at normal viewing size and at 100–200% magnification.

Verify:

  • Full-frame coverage with no unintended empty areas.
  • Dense, short horizontal segments rather than ordinary pixel noise.
  • Grayscale dominance with scattered subtle chromatic details.
  • Consistent overall brightness and density between frames.
  • Continuous per-frame pattern evolution.
  • No excessive color saturation or large chromatic blocks.
  • No broad smearing or unrelated geometric distortions.
  • The very thin vertical detail near the right edge.
  • Correct frozen behavior when Animate With Time is disabled.

Do not claim visual accuracy until the actual native plugin output has been rendered and compared against the reference.

12. Final Integration

Integrate this as a dedicated VHSart preset using the most suitable existing engines.

Do not merge its visual identity with Tracking Damage, Snow, Sync Collapse, Split-Band Chromatic Collapse, or other distinct effects.

The final result must preserve the reference’s defining identity:

Dense full-frame horizontal static, tiny irregular line segments, restrained scattered chroma noise, stable overall intensity, continuous per-frame flicker, and a very fine right-edge vertical line.

Deliver the completed implementation within the existing VHSart project without breaking other effects or presets.
