VHSart — SPLIT-BAND CHROMATIC COLLAPSE

Dedicated Procedural Engine — VHS DAMAGE LAB

1. Objective

Implement a dedicated native C++ procedural effect engine inside VHSart’s VHS DAMAGE LAB, based on the supplied reference video video_1.mp4.

Create a new preset named:

Split-Band Chromatic Collapse

This effect must reconstruct the reference’s distinctive dual-zone visual structure:

* Upper Zone: Dense, rapidly changing, multicolored horizontal static, fragmented chroma noise, short horizontal color streaks, and irregular scanline interruptions.
* Lower Zone: Dense vertical RGB color streaks and adjacent multicolored columns, interrupted by thin horizontal brightness dropouts and flickering signal breaks.
* Shared Artifacts: Intermittent horizontal cuts, irregular brightness fluctuations, saturated color separation, and unstable frame-to-frame patterns.

The result must reproduce the actual visual structure and behavior, not merely apply generic VHS noise, RGB splitting, or colored scanlines.

3. Core Engine Architecture

Create:

Split-Band Chromatic Collapse Engine

The engine must contain three independently controllable procedural components.

A. Upper Colored Static Zone

Reconstruct the upper approximately 40% of the reference frame.

Visual characteristics:

* Dense multicolored horizontal interference.
* Small rectangular and fragmented noise cells.
* Short horizontal streaks with irregular lengths.
* Strong RGB separation and chromatic fragmentation.
* Randomly changing red, green, blue, cyan, magenta, and other saturated color fragments.
* Irregular dark and bright interruptions.
* Fine horizontal scanline-like structures.
* High-frequency, rapidly changing visual activity.

Implementation requirements:

* Generate noise procedurally using deterministic coordinate-based hashing or a suitable PRNG.
* Use horizontally elongated cells rather than ordinary square pixel noise.
* Support independently adjustable horizontal and vertical cell dimensions.
* Introduce row-dependent offsets and fragmented horizontal segments.
* Allow color channels to have partially independent distributions.
* Support density variation, brightness variation, and temporal evolution.
* Avoid uniform RGB television static.

B. Lower Vertical Color-Streak Zone

Reconstruct the lower approximately 60% of the reference frame.

This is a primary visual component and must receive particular attention.

Visual characteristics:

* Numerous adjacent vertical color columns.
* Narrow, medium-width, and occasionally wider vertical streaks.
* Highly saturated red, green, blue, purple, magenta, and mixed RGB colors.
* Irregular boundaries between neighboring columns.
* Mostly vertical continuity across the lower region.
* Local horizontal interruptions, brightness cuts, and flickering segments.
* Changing column positions, widths, and colors between frames.

Implementation requirements:

* Divide the horizontal image axis into variable-width procedural segments.
* Generate column boundaries using deterministic hashes and controlled distributions.
* Allow neighboring columns to have different color values.
* Support controlled variation in column width, density, saturation, and brightness.
* Introduce subtle vertical color modulation without destroying the vertical streak structure.
* Add optional horizontal fragmentation within individual columns.
* Avoid turning the result into a simple vertical gradient or regular color-bar generator.

The columns must have a convincing irregular analog-interference appearance.

C. Horizontal Dropout & Flicker System

Create a shared secondary component operating across both zones.

Visual characteristics:

* Thin horizontal bright and dark interruptions.
* Short broken horizontal streaks.
* Irregular brightness flashes.
* Small signal-like discontinuities.
* Greater visibility in the lower vertical-streak region.
* Occasional interruptions extending across multiple columns.

Implementation requirements:

* Generate horizontal events with variable length, thickness, brightness, and opacity.
* Support independently controlled light and dark dropouts.
* Allow events to affect luminance only or luminance and chroma together.
* Support irregular temporal appearance and disappearance.
* Avoid uniform full-frame scanlines.

4. Split-Band Spatial System

Create a proper spatial separation system.

The horizontal division must be adjustable through:

Split Position

Default: approximately 40% of frame height.

Range: 0–100%.

The upper and lower regions must be calculated from normalized frame coordinates so the effect scales correctly across different resolutions and aspect ratios.

Additional controls:

* Split Position
* Split Boundary Softness
* Split Boundary Instability
* Upper Zone Height
* Lower Zone Height
* Independent Zone Enable/Disable

The division should remain recognizable but may exhibit subtle temporal instability when enabled.

Do not hardcode the reference’s 40/60 division into the rendering algorithm.

5. Procedural Pattern Generation

The entire effect must be generated mathematically during rendering.

Do not use:

* Pre-rendered images.
* Video overlays.
* GIF animations.
* Imported static noise textures.
* Baked frames.
* Pre-generated visual effect assets.

Build the patterns from procedural functions, coordinate-based noise, hashes, controlled random distributions, color-channel calculations, and temporal modulation.

The generator must support:

* Reproducible random patterns using a user-controlled Seed.
* Optional temporal variation.
* Independent random streams for the upper zone, lower zone, and horizontal dropouts.
* Resolution-independent behavior.
* Stable rendering when temporal animation is disabled.
* Deterministic results for the same frame, time, and Seed.

Avoid unnecessary per-pixel expensive calculations where scanline, segment, or block-level generation can achieve the same visual quality.

6. Input and Compositing Modes

The reference appears dominated by the generated interference itself, but the engine must also be practical when applied to ordinary footage.

Color Source

In Full Generated Signal mode, the engine must be capable of producing the complete reference-like appearance without requiring recognizable source footage.

In compositing modes, it must preserve the original image structure where appropriate instead of blindly replacing the entire frame.

8. Temporal Behavior

The supplied reference demonstrates abrupt changes between consecutive frames.

Reconstruct this behavior using independently evolving procedural patterns.

Requirements:

* Upper noise must change irregularly over time.
* Lower vertical columns must change their positions, widths, and color arrangements.
* Horizontal dropouts must appear and disappear independently.
* Brightness flicker must not be synchronized unnecessarily across the entire frame.
* Support different temporal speeds for each component.
* Support a static mode with a fixed Seed.
* Support deterministic frame-based animation.

Do not simply animate the entire image with one global random Seed. That would cause every component to change together and produce an artificial result.

Use independent temporal streams while maintaining reproducibility.

9. Visual Matching Requirements

Use the supplied video_1.mp4 as the primary visual target.

Prioritize these characteristics in order:

1. Clear horizontal separation between the two visual zones.
2. Dense multicolored horizontal interference in the upper region.
3. Distinct vertical multicolored streaks in the lower region.
4. Irregular horizontal interruptions crossing the lower columns.
5. Strong saturated RGB color separation.
6. Independent temporal changes in the two regions.
7. Irregular brightness flashes and dark interruptions.

The lower vertical streaks must not become ordinary vertical gradients.

The upper static must not become ordinary monochromatic noise.

The horizontal dropouts must not become continuous decorative scanlines.

The combined result must retain the reference’s unusual dual-zone identity.
