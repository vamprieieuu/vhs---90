VHSart — Dark-Field Horizontal Static & Top Strip

Native C++ After Effects Plugin — Implementation Prompt

Implement a dedicated VHSart preset named Dark-Field Horizontal Static & Top Strip, based on the supplied reference video video_1.mov (approximately 1.003 seconds).

The effect consists of a dark or black field covered with small, horizontally elongated white and light-gray noise fragments, short horizontal streaks, and fine luminous speckles. A narrow, denser static region is concentrated near the top edge.

Its defining characteristic is the temporal variation in overall noise density: the static becomes noticeably denser and brighter in certain frames, then returns to a lighter distribution.

This is primarily a Dark-Field Horizontal Luma Static effect, not a colored VHS distortion effect.

1. Inspect Existing VHSart Engines Before Implementation

Inspect the complete project and identify existing implementations for:

  • Static and signal noise.
  • Horizontal noise segments and streaks.
  • Dropout generation.
  • Luma and monochrome noise.
  • Noise distribution and density controls.
  • Temporal variation and random seed generation.
  • Generated signal and compositing modes.

Reuse existing engines wherever possible.

Do not create a duplicate static or noise engine if an existing implementation can be extended to reproduce the reference.

The preferred architecture is a dedicated preset configuration using existing VHSart engines, with a small extension for the top-weighted density distribution and temporal density pulse if these features are not already supported.

Do not modify unrelated presets or break existing functionality.

2. Dark-Field Horizontal Luma Static

Reconstruct the main visual component as a dark-field noise system.

Required appearance:

  • Predominantly black or very dark background.
  • Small white and light-gray luminous fragments.
  • Short horizontal lines and horizontally elongated speckles.
  • Irregular spacing and distribution.
  • Medium-to-high overall density, varying over time.
  • Fine-to-medium detail, avoiding oversized pixels and large blocks.
  • Predominantly monochromatic output.
  • Very subtle blue or purple contamination may be allowed, but strong chromatic noise must not dominate.

The noise should appear as irregular analog signal fragments rather than ordinary circular digital particles.

Spatial behavior

Distribute noise across the entire frame, but apply a stronger density bias near the upper edge.

The upper region must remain visibly denser than the rest of the image, including during lower-density frames.

Do not create a large, sharply separated tracking band. The upper concentration should feel like a naturally denser static region.

3. Top Dense Strip System

Implement a spatial density modifier for the upper portion of the frame.

Requirements:

  • Concentrate additional horizontal fragments near the top edge.
  • Make the upper strip relatively narrow.
  • Allow its height and density boost to be adjusted independently.
  • Blend its density smoothly into the rest of the frame.
  • Preserve the underlying full-frame noise distribution.

Expose:

  • Top Strip Enable.
  • Top Strip Height.
  • Top Strip Density Boost.
  • Top Strip Brightness.
  • Top Strip Transition / Falloff.

This system should modify the distribution of the existing static generator rather than create a completely separate noise engine.

4. Temporal Density Pulse

The reference exhibits changing noise density across frames.

The density is lighter around 00:00.000, reaches a stronger peak around 00:00.250, remains variable around 00:00.500, and becomes lighter again around 00:00.750.

Treat these timestamps as visual observations, not hardcoded timing requirements.

Implement a temporal density modulation system that can produce:

  • Low-density frames.
  • Medium-density frames.
  • High-density peaks.
  • Irregular transitions between density levels.
  • Frame-to-frame variation in fragment positions, lengths, and brightness.

The density pulse should affect the entire static distribution while preserving the upper-strip density bias.

Support:

  • Automatic procedural variation.
  • Manual keyframe control where practical.
  • Frozen/static mode.
  • Adjustable pulse intensity.
  • Adjustable animation speed.
  • Adjustable temporal randomness.

Do not force a perfectly periodic pulse. The reference does not establish a reliable repeating cycle.

5. Horizontal Fragment Generation

Use the existing horizontal segment or dropout generation system if available.

The generated elements should include:

  • Fine horizontal speckles.
  • Short horizontal fragments.
  • Slightly elongated luminous particles.
  • Irregular short streaks.
  • Variable brightness.
  • Variable segment lengths.

Use deterministic hash-based procedural generation, with spatial inputs such as segment coordinates, row coordinates, and the effective temporal seed.

Avoid generating uniform horizontal scanlines across the entire frame.

The objective is a dense but irregular field of short horizontal signal fragments.

6. Monochrome Luma Architecture

Keep the main effect monochromatic.

The generated static should primarily use equal or nearly equal RGB channel values to create white and gray luminous noise.

Provide independent control over:

  • Luma Intensity.
  • Luma Contrast.
  • Fragment Brightness.
  • Brightness Variation.
  • Optional Subtle Chroma Amount.

The subtle chroma option must remain restrained and must not transform the preset into a saturated RGB static effect.

8. Input and Compositing Modes

Support the existing VHSart output and compositing architecture:

  • Generated Dark-Field Signal.
  • Apply Over Original.
  • Screen.
  • Add.
  • Input Blend.

The generated dark-field mode must be capable of producing the reference independently, without requiring an underlying image.

When applying the effect over footage, make the interaction between the original image and generated luminous noise predictable.

Preserve alpha correctly and handle premultiplied alpha consistently.

Do not unintentionally turn transparent pixels into opaque black pixels.

9. Deterministic Temporal Rendering

Use deterministic procedural generation.

  • Derive the effective seed from the user seed and composition frame/time when animation is enabled.
  • Preserve a stable pattern when animation is disabled.
  • Ensure the same frame, seed, and parameter values produce the same output.
  • Do not depend on previous-frame memory or render order.
  • Ensure consistent results during timeline scrubbing and repeated renders.

Maintain thread safety and After Effects multi-frame rendering compatibility.

10. Reference Matching and Visual Testing

Render the preset inside After Effects and compare it directly with the supplied reference.

Evaluate:

  1. The dark background and overall contrast.
  2. The small horizontal shape of the luminous fragments.
  3. The irregular distribution of white and gray noise.
  4. The higher density near the upper edge.
  5. The difference between low-density and high-density frames.
  6. The temporal variation in fragment positions and brightness.
  7. The absence of excessive color, geometric distortion, and oversized particles.

Inspect the output at 100%–200% magnification to verify that the generated fragments are horizontally elongated rather than ordinary round particles.

Compare multiple corresponding frames, not only a single still image.

Do not claim visual accuracy based solely on successful compilation.

11. Acceptance Criteria

The preset is complete only when:

  • The background remains predominantly dark.
  • White and light-gray horizontal fragments cover the frame irregularly.
  • The upper region has a clearly higher static density.
  • Overall density changes over time with visible peaks and quieter frames.
  • Fragment positions, lengths, and brightness vary deterministically between frames.
  • The effect remains predominantly monochromatic.
  • No unnecessary geometric distortion or saturated chroma artifacts are introduced.
  • Generated Signal and input compositing modes work correctly.
  • Alpha, premultiplication, thread safety, and multi-frame rendering are handled correctly.
  • Existing VHSart presets continue to work.
  • The final rendered result has been visually compared against video_1.mov inside After Effects.

Implementation priority: Reuse the existing VHSart static/dropout infrastructure. Extend its spatial density distribution and temporal modulation rather than creating an entirely new noise engine. The upper density bias and frame-to-frame density pulse are the two defining features that must distinguish this preset.
