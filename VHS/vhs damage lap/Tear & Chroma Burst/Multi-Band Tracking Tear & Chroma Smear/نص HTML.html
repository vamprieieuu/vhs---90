VHSart — IMPLEMENT MULTI-BAND TRACKING TEAR & CHROMA SMEAR

Objective

Reconstruct the visual behavior of the supplied reference video video_1.mp4 (approximately 0.85 seconds) as a dedicated, fully procedural VHS effect inside the native C++ After Effects plugin, VHSart.

The target appearance combines:

  • Multiple independently moving horizontal tracking-interference bands.
  • Strong horizontal tearing and scanline displacement.
  • Localized horizontal chroma smearing.
  • RGB/chroma separation and displacement.
  • Short horizontal dropout streaks and brightness flicker.
  • A subtle low-resolution analog tape base with global softness and grain.

The result must reproduce the reference’s distinctive multi-band structure and temporal behavior, not merely apply generic VHS noise or a conventional single tracking bar.

1. Mandatory Project Inspection

Before implementation:

  1. Inspect the complete VHSart project structure and existing rendering architecture.
  2. Identify all existing engines responsible for:


    • Tracking noise and tracking damage.
    • Horizontal displacement and scanline processing.
    • Chroma separation and chroma smearing.
    • Dropouts and signal interference.
    • Grain, noise, softness, and low-resolution simulation.
  3. Reuse and extend existing compatible engines wherever possible.
  4. Do not create duplicate implementations of existing functionality.
  5. Introduce a dedicated engine only for the behavior that cannot be accurately achieved through the existing architecture.
  6. Preserve all existing effects, presets, parameter behavior, and project compatibility.

Do not assume an engine exists merely because its name appears in the project. Inspect its actual implementation before integrating it.

2. Dedicated Engine

Implement:

Multi-Band Tracking & Tear Engine

This engine must independently control multiple horizontal interference bands distributed across the frame.

Each band must have its own procedural behavior, including:

  • Vertical center position.
  • Thickness.
  • Horizontal displacement.
  • Tear intensity.
  • Internal line fragmentation.
  • Chroma displacement.
  • Smear strength.
  • Dropout probability.
  • Brightness flicker.
  • Temporal movement and variation.

Support approximately 1–5 active bands, with 2–3 as the default range.

Bands must be able to overlap, approach one another, separate, and move independently.

Avoid making all bands identical copies with different vertical positions.

3. Horizontal Band Generation

Generate irregular horizontal masks procedurally.

For each band, calculate a time-dependent center, thickness, and intensity using deterministic noise and the selected random seed.

The mask should have:

  • Irregular upper and lower boundaries.
  • Uneven intensity across its height.
  • Fine internal scanline structures.
  • Broken and fragmented horizontal sections.
  • Variable horizontal displacement.
  • Occasional short bright and dark streaks.

The bands should extend across most or all of the image width, but their internal damage must remain irregular rather than forming perfectly uniform rectangular bars.

Use smooth band envelopes combined with high-frequency procedural variation to avoid artificial hard-edged masks.

4. Horizontal Tear and Displacement

Within each active band, independently displace image samples horizontally.

Implement row-based displacement:

sourceX = x - horizontalDisplacement(y, time, band, seed)

Displacement must vary across scanlines and may contain abrupt jumps, short segmented shifts, and fine jitter.

Support:

  • Small continuous horizontal shifts.
  • Strong localized tearing.
  • Segmented horizontal offsets.
  • Irregular scanline displacement.
  • Independent displacement behavior for overlapping bands.

Keep the primary distortion horizontal.

Do not introduce full-frame vertical rolling, global rotation, diagonal shearing, or unrelated geometric distortions.

5. Chroma Smearing and RGB Displacement

Implement localized chroma smearing that follows the active tracking bands.

The effect should produce horizontal color extensions and fragmented color streaks, particularly in high-contrast regions.

Support:

  • Horizontal chroma sample displacement.
  • Independent red, green, and blue channel offsets where appropriate.
  • Chroma-only displacement.
  • Optional limited RGB displacement.
  • Localized color bleeding.
  • Irregular magenta, purple, green, cyan, blue, white, and dark streaks.

Keep chroma damage concentrated inside the bands and their immediate neighboring scanlines.

Do not turn the entire image into a strong RGB-split effect.

6. Dropout and Flicker System

Create a procedural dropout system associated with the horizontal bands.

Generate short, irregular horizontal segments with:

  • Bright flashes.
  • Dark interruptions.
  • White or gray streaks.
  • Colored interference fragments.
  • Uneven segment lengths.
  • Variable opacity and intensity.

The dropout pattern must evolve over time using deterministic randomness.

Avoid uniform repeating patterns and avoid making every segment blink simultaneously.

7. Global Analog Base

Reuse VHSart’s existing compatible processing engines for the background tape appearance.

The base treatment should provide:

  • Subtle global softness.
  • Mild low-resolution character.
  • Fine analog grain.
  • Slight high-frequency detail reduction.
  • Low-intensity global noise.

The base effect must remain relatively restrained. The main visual intensity belongs inside the tracking bands.

Expose independent controls for base softness and global grain without duplicating existing controls unnecessarily.

8. Temporal Behavior

The reference demonstrates intermittent, unstable horizontal interference.

Implement independently evolving band positions and intensities.

Requirements:

  • Bands must move vertically over time.
  • Each band must have an independent temporal phase.
  • Band thickness and intensity may vary gradually or abruptly.
  • Dropout segments must change between frames.
  • Chroma smearing must respond consistently to the active band masks.
  • Temporal behavior must not depend on rendering order.
  • The same frame, time, and seed must always produce the same result.

Support:

  • Animated procedural mode.
  • Frozen/static mode.
  • User-controlled temporal rate.
  • Random Seed.
  • Deterministic frame evaluation and timeline scrubbing.

Do not hardcode the reference’s 0.85-second duration or its observed frame timestamps.

Disabling a component must preserve its stored parameter values.

11. Processing Order

Use a carefully integrated processing pipeline:

  1. Existing VHSart base softness / low-resolution processing.
  2. Existing global grain and subtle analog noise.
  3. Multi-band mask generation.
  4. Horizontal band displacement and tearing.
  5. Localized chroma displacement and smearing.
  6. Dropout and brightness flicker.
  7. Final compositing and alpha handling.

The implementation may reorder compatible stages when technically necessary, but must preserve the intended relationship between the band masks, geometric displacement, chroma smearing, and dropouts.

12. Alpha, Performance, and AE Compatibility

The implementation must:

  • Preserve source alpha.
  • Correctly handle premultiplied RGB.
  • Avoid color contamination in transparent pixels.
  • Support different footage dimensions and pixel formats supported by the existing plugin.
  • Be thread-safe.
  • Support After Effects Multi-Frame Rendering.
  • Avoid shared mutable render state.
  • Use deterministic per-frame randomness.
  • Avoid unnecessary full-frame allocations.
  • Avoid out-of-bounds sampling.
  • Remain stable during timeline scrubbing and repeated rendering.

Follow VHSart’s existing native After Effects SDK architecture and parameter conventions.
