VHSart — IMPLEMENT REFERENCE EFFECT: LOCALIZED TEAR & CHROMA BURST

Implement a new dedicated procedural effect inside VHSart based on the supplied visual reference.

Main objective: Recreate the distinctive combination of a severe horizontal VHS tracking tear and localized, highly saturated chromatic bursts. Do not reduce this effect to generic VHS noise, scanlines, or simple horizontal displacement.

1. Required Custom Engine

Create a dedicated engine named Localized Tear & Chroma Burst.

It must contain three coordinated processing components:

A. Central Horizontal Tear

  • Generate a wide, irregular horizontal distortion band across the image.
  • Apply independently varying horizontal displacements to scanlines or groups of scanlines.
  • Introduce broken dark and bright lines, partial Luma loss, intermittent signal interruptions, and short horizontal image fragments.
  • Concentrate the strongest distortion inside the band while preserving the surrounding image.
  • Allow control over band position, height, irregularity, and distortion strength.

B. Localized Chroma Bursts

  • Recreate the reference’s intense localized color artifacts: purple/magenta smearing and green/yellow/orange/red spectral color bursts.
  • Generate irregular chromatic smears, directional color spreading, and localized saturation amplification.
  • Support independently adjustable positions, regions, directions, spread, and intensity.
  • Do not apply uniform Color Bleed across the entire image.
  • The reference’s visible color locations are starting examples, not mandatory fixed positions for every composition.

C. Global Analog Base

  • Apply subtle image softness and low-resolution signal degradation.
  • Add restrained procedural grain and noise across the frame.
  • Increase noise and interference inside the tear band.
  • Preserve the reference’s relatively clean areas outside the main distortion.

2. Required Controls

Provide these adjustable parameters:

  • Tear Band Position (Y)
  • Tear Band Height
  • Horizontal Tear Amount
  • Tear Irregularity
  • Luma Glitch Amount
  • Chroma Burst Amount
  • Chroma Smear Spread
  • Chroma Saturation
  • Left / Right Burst Position
  • Base Softness
  • Global Noise Amount
  • Random Seed

Use the reference analysis as the starting point for default values:

  • Band position: approximately 45–52% of frame height.
  • Band height: approximately 16–22% of frame height.
  • Tear intensity: approximately 65–85%.
  • Chroma intensity: approximately 55–80%.
  • Base softness: approximately 35–55%.

These are initial estimates, not verified original plugin values.

3. Animation & Randomness

The effect must support deterministic procedural animation.

  • Individual scanline distortions and noise details should vary naturally.
  • Support temporal variation without uncontrolled frame-to-frame flicker.
  • Keep the same Seed and frame time reproducible.
  • Allow animation through After Effects keyframes and timeline rendering.
  • Do not assume that the original reference has a moving tear band; its temporal behavior has not been verified.

4. VHSart Integration

First inspect the existing VHSart architecture and available engines.

Reuse existing Noise, Color, and Softness processing where appropriate. Build the custom Tear & Chroma engine only for functionality that existing engines cannot reproduce accurately.

Add a dedicated preset:

Mid-Band Sync Tear & Chroma Smear

The preset must initialize the effect with reference-based settings while allowing every control to remain editable.

Place it within the appropriate VHS DAMAGE LAB / preset organization without duplicating existing engines or breaking other presets.

5. Technical Requirements

  • Native C++ using the existing Adobe After Effects SDK architecture.
  • Procedural generation only: no reference images, GIFs, videos, or pre-rendered overlays.
  • Correct RGB/Chroma processing and image sampling.
  • Preserve Alpha and handle premultiplied pixels correctly.
  • Support different frame dimensions and resolutions.
  • Ensure deterministic rendering, thread safety, and Multi-Frame Rendering compatibility.
  • Preserve existing plugin build architecture and functionality.

6. Verification

Compare the implementation against the supplied reference at matching dimensions.

Prioritize:

  1. The shape, density, and intensity of the central horizontal tear.
  2. The localized purple and spectral color bursts.
  3. The contrast between damaged and relatively clean image regions.
  4. The analog softness and noise distribution.

Do not mark the effect complete based on parameter creation alone. It must actually render the intended visual result.

Important: Implement the actual processing engine and its integration, not merely a UI mockup or a preset containing generic existing effects.
